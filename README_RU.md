# SONORA 3.0 Preview

Android-плеер с собственным интерфейсом, вдохновлённым принципами навигации Poweramp. Это **не копия Poweramp** и не содержит его исходный код или ресурсы.

## Реализовано
- AMOLED-палитра, библиотека категорий и нижняя панель навигации.
- Просмотр треков, поиск по названию и исполнителю, простые группы по исполнителям и папкам.
- Мини-плеер, отдельный экран воспроизведения, очередь, shuffle/repeat, фоновое воспроизведение через Media3.
- Выбор музыкальной папки и GIF через системный файловый диалог.
- Три режима отображения: без GIF, GIF вместо обложки, GIF на весь экран; затемнение.
- GitHub Actions для сборки debug APK.

## Ограничения
- Эквалайзер пока информационный экран, без обработки звука.
- Нет настоящей спектральной визуализации, редактируемых плейлистов и полноценной индексации жанров/альбомов. Группировка «Альбомы» сейчас использует исполнителя как временную заглушку, «Жанры» не считывает жанр из тегов.
- Не гарантирована корректная адаптация всех экранов в landscape.
- Исходники не были собраны в этой среде; GitHub Actions покажет, успешно ли компилируется APK.

## Обновление в GitHub Desktop
Скопируйте содержимое архива поверх файлов в `Документы/GitHub/sonora-android` (не удаляйте `.git`), затем Changes → Commit to main → Push origin. На вкладке Actions дождитесь зелёной галочки, откройте run → Artifacts → SONORA-3-debug-APK.
