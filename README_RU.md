# SONORA 2.0 beta

Android-плеер с отдельной музыкальной библиотекой, экраном воспроизведения, очередью и двумя режимами GIF: анимация вместо обложки или на весь экран.

## Как обновить через GitHub

1. Открой репозиторий sonora-android.
2. Замени существующие файлы содержимым этого архива (не загружай ZIP целиком).
3. Проверь, что `.github/workflows/build-apk.yml` обновлён.
4. После commit открой Actions → Build SONORA APK → последний запуск.
5. После успешной сборки скачай артефакт `SONORA-2-debug-APK` и извлеки `app-debug.apk`.

**Важно:** это исходный проект, а не готовый APK. Сборка в этом окружении не проверялась. Приложение использует прежний applicationId, поэтому должно обновить SONORA 1.0 при совместимой подписи.

## Реализовано
- Главная библиотека и поиск по трекам, группировка по исполнителям, упрощённые вкладки альбомов/папок.
- Фоновое воспроизведение Media3, очередь, shuffle/repeat, seek.
- Чтение названия и исполнителя из аудиометаданных, когда они доступны.
- Выбор GIF, полноэкранный/обложка, сохранение настроек и папки.

## Ограничения beta
- Эквалайзер пока не реализован; нельзя выдавать его за работающий.
- Вкладки «Альбомы» и «Папки» пока упрощённые, не полноценная медиатека Poweramp.
- Плейлисты и полноценное редактирование очереди пока отсутствуют.
- При замене музыкальной папки старые URI должны оставаться доступными через системное разрешение.
