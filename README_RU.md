# SONORA Android — сборка APK без Android Studio

Проект содержит исходный код Android-приложения SONORA:
- выбор GIF-анимации для фона экрана плеера;
- выбор папки с музыкой через системный Android picker;
- поиск аудиофайлов во вложенных папках;
- воспроизведение через AndroidX Media3;
- фоновое воспроизведение через MediaSessionService;
- очередь, перемотка, shuffle, repeat и управление затемнением фона.

## Самый простой путь получить APK (без установки Android Studio)

В архиве настроен GitHub Actions workflow для облачной сборки.

1. Создай аккаунт на https://github.com (если его ещё нет).
2. Создай новый пустой репозиторий, например `sonora-android`.
3. Распакуй архив на компьютере.
4. Загрузи **содержимое** папки `SONORA_Android` в репозиторий через GitHub → Add file → Upload files. Важно включить скрытую папку `.github` с workflow.
5. Нажми **Commit changes**.
6. Открой вкладку **Actions** в репозитории и выбери workflow **Build SONORA APK**.
7. Когда сборка завершится зелёным статусом, открой запуск workflow, прокрути до **Artifacts** и скачай `SONORA-debug-APK`.
8. Распакуй скачанный артефакт: внутри будет `app-debug.apk`. Перенеси его на Android-телефон и установи. При необходимости Android попросит разрешить установку приложений из используемого источника.

Workflow также запускается автоматически при отправке изменений в ветку `main` или `master`.

## Текущее состояние и ограничения

Это начальная версия 1.0. Код подготовлен, но в этой среде не выполнялась сборка Android SDK и не проводился тест на физическом устройстве. Поэтому APK пока не приложен как проверенный файл; облачная сборка выше — предусмотренный способ получить его.

- Поддерживаются локальные аудиофайлы, которые умеет декодировать Android/Media3. Фактическая совместимость зависит от кодека и устройства.
- GIF выбирается через системный диалог. Для фоновой анимации используется Coil GIF decoder.
- Сканирование папки ограничено глубиной 12 уровней и 2000 файлами для защиты от чрезмерно больших деревьев.
- Воспроизведение должно продолжаться в фоне через MediaSessionService; тестирование на разных версиях Android всё равно необходимо.
- Это debug APK для личного тестирования, не подписанный релиз для Google Play.
